# Chapter 6: Linked Lists

This VS Code-friendly project organizes the JavaScript code extracted from `week10/6 Linked Lists.docx`.

## Included topics

- Singly linked list
- Doubly linked list
- Circular linked list
- Media player playlist built on a doubly circular linked list
- Reverse linked list interview exercise

## Run the examples

```bash
npm run example:all
npm run example:linked-list
npm run example:doubly-linked-list
npm run example:circular-linked-list
npm run example:media-player
npm run example:reverse-list
```
