# Week 11 — Chapters 8, 9, and 10 Project

This VS Code-ready sub-project contains extracted/reconstructed code for:

- Chapter 8: Trees (BST + AVL)
- Chapter 9: Graphs (adjacency list + BFS/DFS)
- Chapter 10: Sorting and Searching algorithms

## Run from project root

```bash
npm run trees
npm run graphs
npm run sorting-searching
npm run all
```

## Visualizers

In `visualizers/`:

- Recursion
- Trees
- Binary Map
- Map Sort

Open those HTML files directly in a browser.

## Raw extraction artifacts

In `extracted-code/`:

- helper script (`extract-docx-code.py`)
- generated snippet dump (`raw-docx-code-snippets.md`)
